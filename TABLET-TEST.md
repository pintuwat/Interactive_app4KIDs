# Tablet test checklist (iPad + Android)

Tick every box on **both** devices after each deploy. Use the real https URL, not localhost.

## Install and offline
- [ ] Page loads on first visit in Safari (iPad) / Chrome (Android) with no console errors
- [ ] **Add to Home Screen** works; the icon is Ollie the owl; it opens full screen (no browser bar)
- [ ] Open the app once online, wait ~15 s, turn on **airplane mode**, reopen: home, letters, games and stories all work
- [ ] Turn network back on, reload: still works (no blank screen)
- [ ] After a new deploy: close the app, open online once, close and reopen: the new version loads

## Audio
- [ ] First tap anywhere, then Ollie's voice speaks the instruction on each screen (iOS needs one tap first)
- [ ] Letter lesson: tapping the big letter says the NAME; the sound button says the SOUND (/s/ not "ess")
- [ ] US flag profile hears American voice; UK flag profile hears British voice (Parent corner shows a warning when the device has no voice for an accent)
- [ ] Compare button (US/UK) on a letter lesson plays the other accent
- [ ] Letter Z: American says "zee", British says "zed"
- [ ] Story: "Read to me" highlights word by word; tapping a word says it
- [ ] Sound effects can be muted in the Parent corner; silent switch / volume behave normally

## Touch and layout
- [ ] Every button is easy to hit with a small finger (≥ 64px); no accidental double-activations
- [ ] Rotate portrait ↔ landscape on every screen: no horizontal scrolling, nothing cut off
- [ ] Tracing: finger drawing follows the finger; page does not scroll or zoom while tracing
- [ ] Build the Word: tiles can be dragged into slots and tapped
- [ ] Bubble Pop: bubbles can be popped; wrong bubble just wobbles
- [ ] Text inputs (nickname) bring up the keyboard and the page is still usable

## Learning flow
- [ ] Create two child profiles with different accents; progress is separate
- [ ] Finish a letter lesson (hear letter, sound and all 3 words) → star appears; trace → second star
- [ ] Play each game to the end → result screen shows stars (never a "you lost" screen)
- [ ] Every 5 stars a sticker celebration appears; sticker book shows it
- [ ] Parent corner: maths gate works, export downloads a file, import restores it, reset asks twice
- [ ] Worksheets print / save as PDF on A4 (tracing sheet, matching sheet)

## Safety
- [ ] No ads, pop-ups or external links anywhere in the child area
- [ ] Profiles use nicknames only
